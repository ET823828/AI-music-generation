# Data

`ai_audio_metrics.json` contains derived signal-analysis metrics for the four retained AI generations:

- `dl_VarA_v5.5`
- `dl_VarB_v5.5`
- `dl_VarB_v4.5`
- `love_story_v5.5`

Metrics include duration, estimated tempo, chroma/Krumhansl-style key estimate, median RMS by reference window, spectral centroid by reference window, whole-track dynamic range, and auto-detected segment boundaries.

The metrics are derived descriptors, not raw audio. They are used as supporting anchors for close listening and should not be treated as a substitute for the paper's Moore-style musical analysis.
