# Generated Audio Artifacts

This directory contains the generated audio outputs analyzed in the paper:

- `driver_license_with_no_emotion.wav` — Suno v5.5, Variant A.
- `driver_license_with_detailed_emotion.wav` — Suno v5.5, Variant B.
- `driver_license_suno_v4.5.wav` — Suno v4.5, Variant B.
- `love_story_suno.wav` — Suno v5.5, control.
- `YuE_driver_license.mp3` — YuE boundary comparison.

These files are included for research auditability. They are not original commercial recordings, and this repository does not grant a reuse license for them.
